# 来源与贡献边界

上游为 <https://github.com/SWE-agent/mini-swe-agent>，基线
`04d809ceab9df28f9adaed044884180159172930`（2.4.6）。保留 MIT 许可及原作者版权。
默认循环、模型适配、交互命令、基础环境、原有文档和测试均属于上游能力。

## 本项目新增

- `VerifiedAgent`、`WrapupAgent` 及有界请求恢复组合。
- `ManagedDockerEnvironment`、候选快照、独立验收、事件记录、进程监督与测试反馈。
- 对应机制测试、固定任务评测脚本、公开回归合同与结果分析。
- 公开版移植：Docker 路径可配置、Key 环境变量、按摘要恢复数据、无付费模型 CI。

实现和文档使用 AI 编程工具辅助，贡献以实际 diff、测试与实验材料为准，不宣称全部代码手写。
这是衍生项目，不是从零自研 mini-swe-agent，也没有上游已合并 PR 的声明。

## 公开整理的边界

没有复制学习仓库中对默认循环、交互入口、模型适配器和本机环境的教学修改。
正式评测仍由 `compare.py` 导出固定上游源码再叠加增强组件。
原学习仓库及原始实验档案保持不变。

公开副本移除上游 PyPI 发布、文档部署及全量依赖 CI，改为无付费模型 Harness 检查。
原工作流可在上游 Git 历史中恢复。发行包改名 `mini-swe-harness`，导入包与兼容命令保持不变；
使用独立虚拟环境，没有发布 PyPI、注册全局命令或覆盖原环境。
