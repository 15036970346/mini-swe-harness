# 运行与评测

所有命令在仓库根目录、已激活 `.venv` 的终端执行。先按 README 安装并恢复运行数据。
答案只供宿主裁判读取，不挂载给 Agent；不要挂载整个项目或 `study/.runtime/`。

## Docker

需要支持 `linux/amd64` 的 Docker CLI 与服务，推荐 Linux x86_64；不自动安装 Docker 或模拟器。

```bash
docker info
docker network inspect mini-eval-internal
# 仅网络不存在时执行；已有同名网络须确认 Internal 为 true。
docker network create --internal mini-eval-internal
```

容器使用内部网络、2 CPU、4 GiB、512 PID，不挂载宿主项目。
CLI 不在 PATH 时设置 `MINI_HARNESS_DOCKER`；服务不是默认地址时设置 `DOCKER_HOST`。
CLI 和 Python Docker SDK 必须连接同一服务：只切换 CLI context 不一定影响 SDK，
需为 SDK 设置正确的 `DOCKER_HOST`（TLS 环境按 Docker SDK 要求配置证书变量）。

集成测试需要 Requests 5414 的固定镜像，首次下载约 GiB 级，占用数 GiB 磁盘。
可先从 `manifest-v1.json` 复制对应 image_name，执行 `docker pull`，避免测试阶段拉取超时。

```bash
MINI_HARNESS_DOCKER_TESTS=1 \
```

相同确定性动作分别运行：提交验证版预算耗尽未交付，预算收尾版冻结并验证非空候选后交付。
使用预设动作，不代表真实模型修复率。


## 独立裁判与单题运行

```bash
python -m venv study/.runtime/evaluation/judge-venv
study/.runtime/evaluation/judge-venv/bin/python -m pip install 'swebench==4.1.0' docker unidiff
python study/evaluation/preflight.py
```

上述前检不替代 empty/gold 控制，不产生模型成绩。按 README 为宿主设置 Key，
下面 output 必须是新目录：

```bash
python study/evaluation/compare.py freeze study/artifacts/my-b3-b4 \
  --wrapup --request-recovery \
  --contract study/evaluation/public-validation-pilot-v1.json

# 不调用模型：空补丁应失败、标准补丁应通过；否则停止。
python study/evaluation/compare.py preflight study/artifacts/my-b3-b4

# 从此处开始产生 API 费用，同题 B3/B4 各一次。
python study/evaluation/compare.py run study/artifacts/my-b3-b4 \
  --variant B3 --variant B4 --limit 1
python study/evaluation/compare.py report study/artifacts/my-b3-b4
```

每题 60 次物理请求、2 美元软阈值、1800 秒；失败请求占预算。
未知费用每次风险预留 0.5 美元，不是账单或费用上界。
已开始未完成的题不会自动重跑；先审计，必要时另建运行，不挑最好结果。

输出含 `report.md`、`summary.json`、`attempts/<任务>/<变体>/agent/` 与 `judge/`。
`verified_submission` / `wrapup_verified_submission` 只表示公开验收通过，独立裁判才决定 `resolved`。

## 固定 10 题复跑

10 份公开合同在 `study/evaluation/contracts/`，排除了两道依赖网络的 httpbin 任务。
以下为 Bash / Zsh 数组语法：

```bash
contracts=()
for contract in study/evaluation/contracts/*.contract.json; do
  contracts+=(--contract "$contract")
done
python study/evaluation/compare.py freeze study/artifacts/repeat-10 \
  --wrapup --request-recovery "${contracts[@]}"
python study/evaluation/compare.py preflight study/artifacts/repeat-10
python study/evaluation/compare.py run study/artifacts/repeat-10 \
  --variant B3 --variant B4 --limit 10
python study/evaluation/compare.py report study/artifacts/repeat-10
```

这是按相同任务／策略创建的新实验，不是原始环境的逐字节重放。
任务顺序按上述文件枚举，依赖、宿主环境和服务端模型别名也可能变化；严格比较须另行冻结这些条件。
历史别名不可用时，另选模型并另记实验。不要修改冻结摘要让旧运行通过校验。

## 工具反馈开关

在新一轮 `freeze` 添加 `--test-feedback`，该轮变体同时启用，默认关闭。
模型收到 `mini-test -q tests/文件.py` 使用说明；入口在当前任务目录直接执行 pytest，
不接受 `cd`、管道或重定向，完整日志位于该轮 `agent/tool-tests/`。
这一功能没有参与 2026-10-09 对照，必须另记实验。

本次公开整理不自动运行付费实验，不重写历史成绩，不部署远程服务或更改虚拟机。
